# Roadmap

## Сделано (v1.0.0)

- [x] Каркас CMake + JUCE 8.0.6, форматы VST3 / AU / Standalone.
- [x] Кассетная петля: стерео-буфер до 60 с, запись/чтение, две головки.
- [x] Free-режим (запись до STOP) и BPM-синхронизация (1/1 … 16/1).
- [x] Varispeed ±24 полутона с кубической интерполяцией Catmull-Rom.
- [x] Направления Forward / Reverse / Ping-Pong / Random.
- [x] Ping-pong без замирания на краю при дробной скорости (0.5, 0.25).
- [x] Плавное перетаскивание маркеров лупа: без амплитудной модуляции и
      скачков головки.
- [x] Overdub: возврат деградировавшей петли в ленту, generation loss.
- [x] Splice: скачки читающей головки с fade и паузой.
- [x] Минимальный линейный ADSR с retrigger-условием по длине петли, слышимым
      release-хвостом и встроенным в шапку TAPE MAP индикатором стадии.
- [x] Карта ленты наполняется прямо во время записи (обновление по версии
      записи, а не по длине ленты).
- [x] Деградация: wear, dropouts, splice, oxide, wow/flutter, hiss,
      saturation, tone.
- [x] Мягкий `softClip` на записи, DC-блокер, санитизация NaN/Inf.
- [x] Выходной пиковый лимитер (вкл/выкл) с мягким потолком.
- [x] Глобальный dry/wet, выходной уровень, финальный кламп ±1.0.
- [x] Транспорт REC / PLAY / STOP / REW / FF / CLEAR.
- [x] Кассетный дисплей: бобины, осциллограмма wet, playhead, REC/PLAY,
      PASS, BPM, WEAR, направление.
- [x] Единый дисплей TAPE MAP: карта всей ленты, бобины, редактор границ лупа
      прямо на карте (START/END, перемещение региона, сброс двойным кликом).
- [x] Параметры `loopStart` / `loopEnd`, окно лупа внутри записанной ленты.
- [x] Музыкальный splice: скачки только по границам фраз, с сохранением фазы.
- [x] Dropouts, квантизованные по фазе фразы.
- [x] Прозрачный bypass при пустой/остановленной ленте (dry не тише).
- [x] Запись не «дакает» вход: fresh recording идёт на полном dry, при overdub
      вход мониторится на единичном уровне.
- [x] Sync Transport: PLAY/STOP следуют переходам транспорта DAW (опция).
- [x] Pedal-style UI: корпус, винты, нобы, секции TAPE / ENVELOPE /
      DISINTEGRATION / TONE / OUTPUT.
- [x] Компактный режим (COMPACT / FULL).
- [x] Тёмная и мягкая светлая тема с сохранением выбора.
- [x] Английские подсказки при наведении.
- [x] Система пресетов: save/load, 10 заводских пресетов, дефолт `dlp 1.1`.
- [x] «Чёрный ящик» `DebugLogger`: lock-free снапшоты, heartbeat, выгрузка
      истории при аномалии, ротация лога.
- [x] Кнопка LOG с индикатором аномалии.
- [x] Офлайн-тесты: лента, деградер, стресс DSP, пресеты, интеграция процессора
      и рендер редактора.
- [x] Сборка Release без ошибок.
- [x] AU проходит `auval`.
- [x] Документация в `doc/`.

## Идеи / далее

- [ ] **Resizable UI** с сохранением пропорций и масштабированием кассеты.
- [ ] **MIDI-управление**: footswitch REC/PLAY/STOP, tap-tempo, CC на параметры.
- [ ] **Браузер пресетов** с категориями, переименованием и удалением.
- [ ] **A/B-сравнение** и undo/redo для пресетов.
- [ ] **Crossfade на стыке петли** — отдельная ручка мягкости шва.
- [ ] **Дополнительные головки** (sound-on-sound, вторая читающая головка).
- [ ] **Модуляция параметров** LFO (speed, tone, feedback) для ещё более
      медленного «расползания» петли.
- [ ] **Tape stop / tape start** как отдельный транспортный жест с инерцией.
- [ ] **Стерео-режимы**: mid/side, независимые скорости каналов.
- [ ] **Нормализация / Auto Gain** для компенсации потерь уровня при сильном
      wear.
- [ ] **Оверсэмплинг** сатурации и лимитера (если понадобится для мастеринга).
- [ ] **CI**: автоматическая сборка и прогон тестов на macOS.
- [ ] **Кастомный шрифт / логотип** и более физичная анимация бобин.

## Известные ограничения

- UI фиксированного размера (1120 × 740, компактный — 500 по высоте).
- Максимальная длина петли — 60 секунд; на медленном BPM значения 8/1 и 16/1
  могут упираться в этот потолок.
- Free-запись автоматически останавливается при заполнении 60-секундного
  буфера.
- Нет MIDI-управления и tap-tempo.
- Нет undo/redo для пресетов.
- Буфер ленты выделяется в `prepareToPlay`; смена sample rate пересоздаёт его.
- CLEAR очищает весь буфер; на очень больших буферах это может дать короткий
  провал в аудио.
